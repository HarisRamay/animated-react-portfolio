# Animated React Portfolio

A 3-page portfolio template built from scratch with:

- React + Vite
- Tailwind CSS v4
- GSAP
- React Router
- Lucide React

## Pages

- `/` — Home
- `/projects` — Projects
- `/contact` — Contact

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

Replace:

- Name
- Email
- GitHub URL
- LinkedIn URL
- Project descriptions
- Project images
- Project links

The contact form is intentionally front-end only. Connect it to an email/API service for real submissions.
